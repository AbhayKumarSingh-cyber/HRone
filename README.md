# HROne Employee Attendance & Analytics API

A robust FastAPI application built for the HROne technical assignment to manage employee attendance tracking, manual correction audit trails, and advanced MongoDB aggregation-based analytics.

## Tech Stack
* **Python 3.11+**
* **FastAPI**
* **MongoDB Atlas** (PyMongo)
* **Pydantic v2**
